# EzyDrive Rentals — Final Submission Checklist

Use this checklist before handing in the coursework.

## Website / database

- [ ] Start Apache and MySQL in XAMPP.
- [ ] Import `database/ezydrive_rentals.sql` into phpMyAdmin.
- [ ] Confirm there are three tables: `users`, `vehicles` and `bookings`.
- [ ] Confirm 12 seed vehicles appear on the Vehicles page.
- [ ] Register a test account, log out, and log back in.
- [ ] Click Book Now on a vehicle; complete a booking.
- [ ] Confirm Booking Details displays the customer and the reservation.
- [ ] Cancel the booking and confirm its status becomes `Cancelled`.
- [ ] Test that two active reservations cannot overlap for the same vehicle.
- [ ] Test the administrator's Create / Read / Update / Delete of vehicle records (see `SETUP_BACKEND.md`).
- [ ] Check navbar, mobile layout, images and the video on About Us.

## Report / repository

- [ ] Replace 'Member 1–4' on About Us with real names and correct responsibilities.
- [ ] Fill member names and student IDs in `PROJECT_REPORT_TEMPLATE.docx`.
- [ ] Insert REAL screenshots from your working XAMPP website for Home, Vehicles, Booking and About Us.
- [ ] Add a screenshot of Booking Details and phpMyAdmin tables (recommended).
- [ ] Fill the test-results table truthfully after running the test plan.
- [ ] Export the completed report to PDF if required by your LMS.
- [ ] Push final code, assets and SQL file to GitHub (do not push `.git` itself as a nested folder).
- [ ] Make sure the repo is accessible to the lecturer and include its link in the report.
- [ ] Submit the report on LMS and be ready to explain each member's contribution.

## Important

The report template is **not** a final report until screenshots, participant details and tested results have been added. Automated code checks cannot replace live MySQL verification.
